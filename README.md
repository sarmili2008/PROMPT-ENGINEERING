- Provides information about the position of each word.
- Helps the model understand word order.

- Identifies relationships between words.

     Definition:

GAN works like a competition between two students.
It contains two main parts:
1. Generator: Creates fake images or data.

Working of GAN
1. Generator creates fake data.

3. Discriminator identifies whether the data is real or fake.
4. Generator learns from the feedback.

It includes:

- TPUs (Tensor Processing Units)
- High-performance computers
- Cloud computing systems
More computing power allows large models to process huge amounts of data and complete training more efficiently.
